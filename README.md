# JavaScript Bootcamp Exercises

JavaScript learning examples for object-oriented programming and ES6 features, including rest/spread syntax and destructuring.

## Structure

- `advancedJavaScript-master/src/oop/`: object-oriented examples.
- `advancedJavaScript-master/src/restSpreadDestructure/`: rest, spread, and destructuring examples.
- `advancedJavaScript-master/package.json`: development server configuration.

## Getting started

Install Node.js and npm. This is a legacy exercise project using `lite-server` and Traceur; dependency compatibility may require maintenance on newer Node.js releases.

```sh
git clone https://github.com/Murat-Selim/Camp_Javascript.git
cd Camp_Javascript/advancedJavaScript-master
npm install
npm run dev
```

Open the URL printed by `lite-server` and inspect the browser console while exploring the examples.

## Tests

`npm test` is currently a placeholder that exits with an error; the repository does not provide an automated test suite. Validate exercise behavior in the browser console.
